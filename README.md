# Hi, I'm Carter (2three1y)

I make web stuff that works with a screen reader first and looks cool second. Usually at an hour I should be asleep.

## What I build

- Accessibility-first web toys and apps. If VoiceOver can't use it, it's not done.
- Music stuff: things that turn typing, stars and Nostr notes into sound.
- Nostr things, because I'm a big Nostr fan and I will tell you about it.
- Way too many side projects. I regret nothing. Okay, maybe a little.

## Stuff I made

- [My website, with everything I've built](https://2three1y.github.io/): the home base.
- [Letter Orchestra](https://2three1y.github.io/letterorchestra/): type letters and they turn into music, with 17 instruments, effects, genre demos and WAV export.
- [Retro Desk](https://2three1y.github.io/retrodesk/): a fan-made Windows 95-style desktop in your browser, boot chime included.
- [Fork Lab](https://2three1y.github.io/forklab/): working offline demos of 8 apps I forked, with fake data and no servers.
- [Tap Party](https://2three1y.github.io/tapparty/): Morse code chat with friends in the browser: tap it, hear it, feel it, or read it in braille.
- [Blind Chess](https://2three1y.github.io/blindchess/): chess you play by sound and keyboard, every move spoken out loud.
- [Earshot](https://2three1y.github.io/earshot/): an offline talking reader and assistant.
- [Relay Radio](https://2three1y.github.io/relayradio/): hear Nostr live, like a radio station.
- [Stargazer](https://2three1y.github.io/stargazer/): my GitHub stars as a sound map. Yes, I star a lot of repos.
- [Dream Nests](https://2three1y.github.io/dreamnests/): live Nostr audio rooms that work with VoiceOver.
- [Retro Voice Jukebox](https://2three1y.github.io/retrovoicejukebox/): old-school robot voices, one of which sings.
- [GameSpeak](https://2three1y.github.io/gamespeak/): reads the text in game screenshots out loud.
